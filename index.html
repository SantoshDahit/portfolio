// Process

My Development Work Process

01

Plan & Architect

Before the first line of code I map the requirements, the data model, and the API surface — clarifying constraints while they're still cheap to change.

02

Build & Secure

Clean, maintainable Spring Boot services with authentication and authorisation designed in from the start, not bolted on before launch.

Ship & Monitor

Dockerised deploys to AWS or GCP, then Prometheus and Grafana on top — plus the ongoing tuning that keeps a live product healthy.
